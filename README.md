Telegram-бот для сбора отзывов клиентов. Клиент оставляет отзыв в боте, владелец проверяет его, и после одного нажатия отзыв автоматически публикуется в Telegram-канал.

Живая демонстрация: бот @feedback_kamidzuki_bot, канал @otzivyvayb

Что умеет

	•	Оценка от 1 до 5 звёзд, одним нажатием
	•	Теги «что понравилось»: скорость, вежливость, ассортимент, атмосфера
	•	Подпись именем или анонимно
	•	Текст отзыва и фото
	•	Модерация: владельцу приходит отзыв с кнопками «Опубликовать» и «Отклонить»
	•	Фильтр мата подсвечивает подозрительные отзывы, решение всегда за владельцем
	•	Публикация в канал одним нажатием
	•	Ответ владельца под отзывом прямо из бота
	•	Благодарность клиенту после публикации

Как это работает

	1.	Клиент открывает бота и проходит короткий диалог: звёзды, теги, подпись, текст или фото.
	2.	Владельцу приходит готовый отзыв с пометкой, если в тексте найден мат.
	3.	Владелец нажимает «Опубликовать», и бот отправляет отзыв в канал, а клиенту приходит уведомление.
	4.	Под опубликованным отзывом владелец может нажать «Ответить на отзыв», и ответ появится в канале.

Технологии

	•	Python 3.12
	•	python-telegram-bot 21 (режим webhook)
	•	Хостинг: Render (бесплатный тариф)
	•	Код: GitHub

Особенности реализации

	•	Режим webhook вместо polling: бесплатный сервис может засыпать, а Telegram будит его входящим сообщением.
	•	Модерация не хранит данные на сервере: отзыв целиком лежит в сообщении, которое получает владелец, поэтому перезапуск сервиса ничего не ломает.
	•	Токен и настройки берутся из переменных окружения, в коде секретов нет.

Запуск

	1.	Создайте бота в @BotFather и получите токен.
	2.	Добавьте бота администратором в канал с правом публикации.
	3.	Выложите код на GitHub и создайте Web Service на Render:
	•	Build Command: pip install -r requirements.txt
	•	Start Command: python bot.py
	4.	Добавьте переменные окружения:

Переменная	Значение
BOT_TOKEN	токен бота из BotFather
OWNER_ID	ваш числовой Telegram ID (команда /myid в боте)
CHANNEL	канал для публикации, например @otzivyvayb
PYTHON_VERSION	3.12.8
